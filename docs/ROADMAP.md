## 第 1 阶段（2 个月）· 毕业底线

目标：被试内 RF-SNN 情绪识别，$(\tau,\omega)$ 用 Koopman 谱初始化。

- [ ] SpikingJelly 环境 + BRF 神经元实现（基于 Higuchi 开源代码改）
- [ ] 谱初始化函数：把估出的 $(f_j, \sigma_j)$ 映射为 $(\tau_j, \omega_j)$
- [ ] 被试内基线跑通（SEED）
- [ ] **神经元消融**：LIF / ALIF / RF(随机初始化) / RF(谱初始化)
- [ ] 记录 $T$、$\bar r$、$S = T\bar r$

**为什么这是底线**：EEG 判别信息在节律里，LIF 只有实特征值、
原理上表示不了振荡，RF 超过 LIF 几乎必然。此时 Koopman 是**工具**
不是**赌注**——不管谱是否被试不变，作为初始化方法都成立。
